# Portfolio site — UI kit
Click-through recreation of the portfolio (source: `Portfolio v2.dc.html` in the Portfolio project).
Screens: **Home** (nav, hero, about, expertise, featured projects, references) → **All projects** index → **Case study** deep dive. Click a project card, "All projects", or nav → Projects.
Components come from the compiled bundle (`window.KushanManaharaDesignSystem_636c69`); kit screens import primitives from `components/`.
Omitted: WebGL background, GSAP/Lenis scroll choreography (v2 orbit carousel → stacked-deck exit, fan stack, wipes), preloader — motion layers, not components. Imagery is picsum placeholders, same as source.
